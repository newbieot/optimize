# PosNew Hub — Optimalisasi Proyek Logistik

Static web application untuk analisis tarif dan profitabilitas proyek logistik.

## Deploy ke Cloudflare Pages

1. Upload seluruh isi repository ini ke GitHub (pastikan `index.html` berada di root).
2. Hubungkan repository ke Cloudflare Pages.
3. Framework preset: **None**.
4. Build command: kosong.
5. Build output directory: `/`.
6. Deploy dan pastikan domain Firebase Authentication mengizinkan domain produksi.

Tidak diperlukan npm atau build step.
